\# Career Plan Generator — Frontend



An AI-powered web app that generates personalized career learning plans.



🔗 \*\*Live\*\*: https://career-planner-claude.netlify.app



\## What it does



Tell it your skills (ranked by priority), available hours, target tenure, and optionally a target JD. Get back:



\- A phased learning plan with action items and target dates

\- Ground rules calibrated to your situation

\- A weekly ledger to track progress

\- Downloadable Word (.docx) and PDF formats



Powered by Claude Sonnet 4.5 via the Anthropic API.



\## Stack



\- Single-file React (no build step — uses Babel standalone)

\- Tailwind CSS via CDN

\- docx.js for Word document generation

\- Deployed on Netlify

\- Backend: Express + Anthropic SDK + Razorpay (separate repo)
